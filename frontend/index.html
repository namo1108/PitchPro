🎨 화면 테마

📱 앱을 안 보고 있을 때도 알림이 오려면, 알림 권한을 허용하고 이 버튼으로 알림을 켜둬야 해요. iPhone은 Safari로 열어 "홈 화면에 추가"한 뒤 그 아이콘으로 실행해야 백그라운드에서도 알림이 옵니다 (사파리 탭으로만 열어두면 화면을 벗어난 뒤엔 알림이 오지 않아요).

🔋 갤럭시(삼성) 폰은 배터리 절약 기능이 브라우저를 자주 꺼서 알림이 늦거나 안 올 수 있어요. 설정 → 배터리 및 디바이스 케어 → 백그라운드 사용 제한에서 Chrome(또는 사용 중인 브라우저)이 "절전 앱"/"잠자기 앱" 목록에 있으면 빼주세요. 홈 화면에 추가해서 썼다면 그 앱도 같은 목록에서 확인해보세요.

🔔 갤럭시인데 알림이 배지로만 뜨고 화면 위로 안 뜬다면(팝업 X): 설정 → 알림 → 고급 설정 → "앱별 알림 카테고리 관리"를 켠 다음, 설정 → 앱 → PITCH PRO → 알림 → 카테고리 → 일반에 들어가서 "팝업으로 표시"가 켜져 있는지 확인해주세요. (플로팅 알림이 "버블"이나 "스마트 팝업"으로 설정돼 있으면 오히려 방해될 수 있어요 - "사용 안 함"을 추천해요)
